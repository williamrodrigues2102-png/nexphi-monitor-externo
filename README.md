# Monitor externo NexPhi

[![NexPhi visto de fora](https://github.com/williamrodrigues2102-png/nexphi-monitor-externo/actions/workflows/monitor.yml/badge.svg)](https://github.com/williamrodrigues2102-png/nexphi-monitor-externo/actions/workflows/monitor.yml)

Verde = tudo respondendo na última rodada. Vermelho = algo fora: clique no selo, abra a rodada e o passo "Checar os sites".

Checa a cada 5 minutos, de fora dos servidores, se o NXP, a API, o Portal e o
Painel de Servidores respondem. Falha = e-mail do GitHub. Resultado também
aparece no Painel de Servidores (serviço externo "Monitor externo").
